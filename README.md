# pandas-learn 🐼

A repository for learning and practicing data manipulation and analysis with the Python `pandas` library.

## 📌 About This Repository
This project serves as my personal workspace to master data manipulation, cleaning, and analysis using pandas. It includes Jupyter Notebooks, Python scripts, and practice datasets where I experiment with different pandas functions and data analysis techniques.

## 📂 Repository Structure
- **`data/`**: Directory containing datasets used for practice.
- **`matches.csv`**: Sample dataset (IPL matches) currently being used for practice.
- **`basics-filtering.ipynb`**: Jupyter Notebook containing exploratory data analysis and pandas topic.

## 🚀 Topics Covered (So Far)
- Reading and writing data (CSV files)
- DataFrame basics and inspection
- Data filtering and selection
